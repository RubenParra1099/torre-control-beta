# Torre de Control BETA

Propuesta de sistema de indicadores de control y toma de decisiones para **Servicio Integral BETA** (última milla).

Incluye diagnóstico, arquitectura, 8 módulos de captura, catálogo de 28 KPIs, tablero demo interactivo con mapas (datos simulados), reglas de decisión y hoja de ruta.

Sitio estático: un solo `index.html`, sin build. Se despliega en Vercel tal cual.

> Las cifras del tablero demo son de ejemplo y no corresponden a datos de BETA.
