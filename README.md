# Torre de Control BETA

Propuesta de sistema de indicadores de control y toma de decisiones para **Servicio Integral BETA** (última milla para supermercados, e-commerce y centros comerciales).

Incluye diagnóstico, servicios, arquitectura, 8 módulos de captura, árbol de indicadores (Entrega perfecta), catálogo de 28 KPIs con tendencia, matriz de SLA por segmento, tablero demo interactivo con 14 vistas y mapas (datos simulados), reglas de decisión y hoja de ruta.

Sitio estático: un solo `index.html`, sin build. Se despliega en Vercel tal cual.

> Las cifras de indicadores y del tablero demo son de ejemplo y no corresponden a datos de BETA.
